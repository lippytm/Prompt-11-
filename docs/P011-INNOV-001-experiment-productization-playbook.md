# P-011-INNOV-001 — Innovation Experiment and Productization Playbook

## Definition of ready

An innovation is ready for structured evaluation when it has a stable ID, named problem, affected audience or ecosystem, source/artifact references, privacy class, reality label, expected value, known risks, and one testable next action.

## Definition of done for Q2

- architecture and schemas exist;
- synthetic portfolio and database exist;
- scoring and recommendation logic are tested;
- artifact intake is traceable;
- workbook views are usable;
- critical gates are visible;
- human approval remains pending;
- no production action is claimed.

## Experiment pattern

1. State the hypothesis.
2. Choose one leading and one outcome metric.
3. Set a maximum budget and timeout.
4. Use synthetic, public, or specifically approved minimum-necessary data.
5. Define stop conditions before execution.
6. Record defects and unintended effects.
7. Compare independent AI treatments only after each is complete.
8. Require an identified human decision.
9. Correct, supersede, or retire unsuccessful work.

## Productization sequence

`learning object → no-transaction pilot → Q3 evidence → customer-support plan → transparent price/cost hypothesis → bounded paid pilot → Q4 decision → monitored release`

Revenue is a measured consequence of customer value and operational quality; it is not proof that the product is safe, truthful, legal, accessible, or sustainable.
