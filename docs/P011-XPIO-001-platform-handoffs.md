# P-011-XPIO-001 Cross-Platform Handoff Contracts

## Shared packet

Every destination receives a bounded Work Packet with objective, privacy class, model line, approved sources, permitted tools, budget, timeout, acceptance criteria, required gates, and exact return schema.

## ChatGPT Business

Produces Prompt #11 orchestration, implementation planning, structured drafts, tests, quality evidence, and the independent ChatGPT edition. Reusable results are committed to GitHub.

## Gemini and NotebookLM

Receives a source-grounded research packet. Required return: source manifest, claim-to-source matrix, independence groups, contradictions, unresolved questions, and an independent treatment. It may not copy ChatGPT or Claude output and label repetition as verification.

## Claude and Fabric Hermes

Receives a separate red-team and architecture packet. Required return: risks, contradictions, identity and permission findings, failure scenarios, recommended tests, and bounded implementation alternatives. Hermes routes and audits but does not approve truth, financial action, or release.

## Slack

Receives only status, blockers, review requests, incidents, and canonical links. Slack is not the evidence vault, database of record, or approval authority.

## lippytmai.zo.computer

Receives only an approved Runtime Experiment Passport with code hash, synthetic data, permissions, budget, timeout, logging, monitoring, rollback, shutdown, and revocation. No production use without separate Q4 approval.

## Return envelope

Every platform returns: platform ID, model and version when known, work packet ID, correlation ID, artifacts, sources, tests, defects, costs, privacy state, gate findings, unresolved questions, and next action.
